## O que tem aqui

- **Projetos** com GIF de demonstração e link para o case completo
- **Demo ao vivo:** validador de chave de acesso NF-e (dígito verificador em módulo 11), em JavaScript puro
- **Case studies** no formato problema → solução → resultado
